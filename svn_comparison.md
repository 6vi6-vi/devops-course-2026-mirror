# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

Ветка в Git — это указатель на коммит. Создание ветки не копирует файлы и не дублирует историю,
поэтому операция мгновенная и не зависит от размера проекта.

Ветка в SVN — это копия директории на сервере, физически дублирующая структуру. Чем больше проект,
тем дольше и дороже создание ветки. 

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN — централизованная система, коммит уходит на сервер и требует соединения. Локально можно только редактировать файлы, но зафиксировать изменения — только онлайн.

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

- Хранение больших бинарных файлов (арт, видео, 3D-модели)
- Контроль доступа к отдельным папкам
- Работа с частичными копиями репозитория
- Простые проекты, где не нужны ветки и распределённая работа
